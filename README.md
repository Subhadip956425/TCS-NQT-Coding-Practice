# TCS NQT Coding Practice

A structured collection of coding problems and Java solutions prepared during my TCS National Qualifier Test (NQT) preparation.

This repository contains programming questions, problem-solving approaches, and optimized Java solutions to help students prepare for TCS NQT and other technical assessments.

## Topics Covered

- Basic Programming
- Number-based Problems
- String Manipulation
- Arrays
- Sorting and Searching
- Pattern Programming
- Data Structures and Algorithms
- Previous TCS NQT Questions

## Programming Language

- Java

## Repository Goals

- Practice coding problems regularly.
- Improve logical thinking and problem-solving skills.
- Maintain a structured collection of solutions.
- Help fellow students preparing for TCS NQT.

## How to Use

1. Choose a topic.
2. Open the corresponding problem.
3. Understand the problem statement.
4. Run the Java solution.
5. Practice solving it independently.
